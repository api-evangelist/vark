# Vark (Aardvark)

Vark is the Felicis portfolio listing for Aardvark, the social search / knowledge-market startup founded in 2007 by Max Ventilla, Nathan Stoll, Damon Horowitz, and Rob Spiro (The Mechanical Zoo). Google acquired Aardvark on February 11, 2010 for $50 million and shut the service down in September 2011.

The company is defunct and published no public API, so this profile carries no API artifacts.

- Backed by: felicis
- Status: defunct (acquired by Google 2010-02-11, shut down 2011-09)
- Original domain: vark.com — no longer resolves (probed 2026-07-21)
- Felicis-listed URL: https://vark.io — currently hosts an unrelated SMS meeting-reminder product (Saasology LLC), not this company
